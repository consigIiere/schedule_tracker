# 📅 Personal Schedule & Workout Tracker Bot

Асинхронний Telegram-бот для ведення щоденних звичок, разових завдань та 2-тижневих циклів силових тренувань.

## 🛠 Стек технологій
- **Python 3.11**
- **aiogram 3.x** (Асинхронний фреймворк для Telegram Bot API)
- **PostgreSQL** + **asyncpg** (Реляційна база даних та асинхронний драйвер з Connection Pooling)
- **FSM (Finite State Machine)** (Контроль станів користувача)
- **python-dotenv** (Управління змінними оточення)

## ✨ Ключовий функціонал
- **Single-Message UI**: уся взаємодія відбувається в одному динамічному повідомленні без спаму в чаті.
- **2-тижневий тренувальний спліт**: автоматичний розрахунок парності/непарності тижня для чергування програм.
- **Гнучке керування розкладом**: швидке додавання, заміна та очищення вправ за днями тижня.
- **Щоденні звички та разові таски**: підтримка щоденних регулярних справ з відміткою виконання (✅/❌).
